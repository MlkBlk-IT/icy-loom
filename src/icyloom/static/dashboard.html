Quickstart — up and running in three steps

No build step, no CDN, no cloud. Python on the machine, everything on 127.0.0.1.

1 · Install

once
git clone https://github.com/MlkBlk-IT/icy-loom cd icy-loom && pip install -e .

One clone, one editable install. No venv is forced — use yours if you have one.

2 · Launch

every time
icyloom serve python tools/tray.py  # optional tray

The stack opens four ports: gateway 8150, MCP HTTP 8151, SSE 8152, this console 8153.

3 · Point your client

one env var
export OPENAI_BASE_URL=http://127.0.0.1:8150/v1 export MCP_HTTP_URL=http://127.0.0.1:8151/mcp

Any OpenAI- or Anthropic-compatible client works. Cache hits, compression and the tool tax are all measured here.

What happens next

zero config

Nothing to tune

  • The gateway listens on 8150 and forwards to your upstream as soon as a request lands.
  • The cache is keyed on the normalized prompt — identical calls are answered locally.
  • The ledger records every call, hit or miss, in the single SQLite file.

Reading your first numbers

  • Open Overview — five KPI cards, live.
  • Cache rate is the share of calls answered from the cache.
  • Gain is avoided ÷ (paid + avoided); the target line is 35%.

Guide — how to read this console

What the numbers mean, where a request travels, and which knobs to turn.

The path of a request

client → gateway → cache → upstream → registry → console

Reading the metrics

  • Hit — the answer came from the cache, so those upstream tokens were avoided, never billed.
  • Miss — the call went upstream; its tokens are real (upstream usage), never estimated.
  • Gain = avoided ÷ (paid + avoided). The operating threshold is 35%.
  • p95 — 95% of calls are faster than that.
  • A negative saving is possible: compression can cost more tokens than it saves. It is shown as measured.
  • Everything on this page is read from v_token_ledger, the unified registry.
  • All timestamps are UTC — one single clock, from the database to the charts.

The 13 MCP tools

Shortcuts & tips

  • 1…8 jump to a view, R refreshes, P pauses, E exports, C compacts.
  • The side panel switches view: every view is live, none of them is a static page.
  • The 3D relief spins with the mouse; the map is read with the finger.
  • Ports: gateway 8150, MCP HTTP 8151, SSE 8152, console 8153.
  • Everything binds to 127.0.0.1 — nothing leaves the machine.
  • Compact in the side panel shrinks everything for a laptop screen.
  • Export downloads the exact JSON the page is drawing.

Fine print

nothing hidden

Data

  • All figures come from the SQLite v_token_ledger — no sampling, no estimation.
  • Timestamps are UTC, one clock from the database to the ink.
  • The page is read-only: it never writes to the registry.

Privacy

  • Every port binds to 127.0.0.1. No telemetry, no external call.
  • No CDN and no external font: the page draws everything with local code.
  • Cache keys are hashes of normalized prompts — the raw text stays local.

Troubleshooting

  • Console blank? Check 8153/health — it should read healthy.
  • No new numbers? Open Audit live to confirm events are landing.
  • Everything frozen? The Reconnect button in the Window bar re-opens the stream.
